Enter Ghost Tag, a spooky game that lets you hide, hunt and survive.

There is one hunter. There is a swarm of phasing ghosts. Hunter must dodge the Reclaimer collect Ghost Tokens and unlock cosmetic looks. Can the hunter turn everyone human before time runs out? Bring friends. Survive all three haunted arenas.

When the round begins, hunters search locations and try to stop the ghost. Ghosts can slip through walls stalk from the shadows and taunt hunters. Can hunters catch the ghost before time runs out?

Explore the Graveyard, Haunted School and Haunted Hospital. Earn Ghost Tokens, roll for ghost skins and show off your favorite look.

## Project file

The repository includes `Ghost-Tag.rbxl`, a Roblox place file containing the game. To open it in Roblox Studio, use **File → Open from File** and select the file.

## Get the project with Git

Install [Git](https://git-scm.com/downloads) and Roblox Studio first.

### Clone the repository once

Open PowerShell or Terminal and run:

```bash
git clone https://github.com/bhimesh-GR8/Ghost-Tag.git
cd Ghost-Tag
```

### Pull the latest version later

From inside the `Ghost-Tag` folder, run:

```bash
git pull origin master
```

Then open `Ghost-Tag.rbxl` from that folder in Roblox Studio.

### Save and share your changes

Open the place file from the cloned repository folder so Studio edits the working copy. After saving your changes in Studio, run:

```bash
git add Ghost-Tag.rbxl
git commit -m "Update Ghost Tag"
git push origin master
```

### Important note about the place file

The `.rbxl` file is a complete binary snapshot. Git can store and download it, but it cannot combine two people’s edits to the same place file. Pull the latest version before editing, and coordinate so only one person replaces the place file at a time.

To publish an updated local place to Roblox, open it in Studio and use **File → Publish to Roblox As…**. Select the existing Ghost Tag experience and the correct place before confirming an overwrite.
